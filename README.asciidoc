# study-awsdvac02
## Initial Set Up for Ansible

==== Run `ssh-setup.sh`

Execute 'ssh-setup.sh' in the controller server first.
----
/home/vagrant/ssh-setup.sh
----
This will set up SSH connection from the controller to the target server.

==== Run Ansible Playbook to install AWS CLI

Execute Ansible Playbook in the '/home/vagrant/ansible'
----
ansible-playbook site.yaml -i inventories/hosts.ini --ask-vault-password
----
